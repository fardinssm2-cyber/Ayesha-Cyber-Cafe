FREE PUBLISHING WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/ and verify your email.
2. Create a NEW PUBLIC repository named ayesha-cyber-cafe-website.
3. Open the repository and choose Add file > Upload files.
4. Extract this ZIP on your computer, then upload index.html, README.txt, and the assets folder (upload the files inside it too). Do not upload only the ZIP file.
5. Click Commit changes. Make sure index.html is at the repository root, not inside another folder.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch; select branch main and folder /(root), then Save.
8. Wait a few minutes and refresh Settings > Pages. Click Visit site when the link appears. It will look like https://YOUR-GITHUB-USERNAME.github.io/ayesha-cyber-cafe-website/
